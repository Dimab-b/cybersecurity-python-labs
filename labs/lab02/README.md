## 4. Запуск Завдання 2 (аналіз auth.log)

```bash
python -m labs.lab02.main analyze
```

Дані та звіт за замовчуванням беруться з каталогу варіанта:

```bash
python -m labs.lab02.main analyze \
  --auth-log labs/lab02/data/data_v04/auth.log \
  --threshold 5 \
  --window-min 5 \
  --output-json labs/lab02/data/blocklist_ips.json
```

### Параметри CLI

| Параметр          | Опис                                                   | За замовчуванням            |
| ----------------- | ------------------------------------------------------ | --------------------------- |
| `--auth-log`      | Шлях до файлу журналу автентифікації SSH               | `data/data_v04/auth.log`    |
| `--threshold`     | Поріг невдалих спроб у межах вікна                     | `5`                         |
| `--window-min`    | Розмір часового вікна у хвилинах                       | `5`                         |
| `--output-json`   | Шлях до підсумкового JSON-звіту                        | `data/blocklist_ips.json`   |
| `--log-file`      | Необов'язковий файл журналу роботи утиліти            | (вимкнено)                  |
| `--log-level`     | Рівень консольного логування                           | `INFO`                      |

### Поведінка при помилках

- Якщо файл `--auth-log` не існує — виводиться помилка
  `[ERROR] Файл журналу не знайдено: ...`, код виходу `1`.
- Якщо у файлі немає жодного коректного рядка — виводиться попередження,
  код виходу `1`.
- `--threshold` та `--window-min` мають бути додатними; інакше
  збуджується `ValueError`.
- Нерозпізнані рядки журналу пропускаються з повідомленням у режимі `DEBUG`.

## 5. Що робить утиліта (варіант 4)

1. Розбирає рядки `Failed password` та `Accepted password` регулярним
   виразом, витягуючи IP, користувача, мітку часу та хост.
2. Агрегує невдалі спроби за IP через `collections.defaultdict`.
3. Знаходить ковзне часове вікно з максимальною кількістю невдалих спроб.
4. Формує список IP, що підлягають блокуванню.
5. Виводить звіт у консоль, пише тривоги через `logging.error` та зберігає
   JSON-звіт із блок-списком.
